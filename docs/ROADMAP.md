# NEXUS AI — Long-term Roadmap

NEXUS is a large iterative product. Milestones are delivered independently and are not complete until tests and review pass.

## Phase 0 — Repository foundation
- Canonical repository and project conventions
- React/Vite web foundation
- Express API and SQLite conversation persistence
- Gemini/OpenAI server-side provider adapters
- Capacitor Android wrapper configuration
- CI build and test workflow

## Phase 1 — Core AI Brain
- Provider management and model capabilities
- Streaming responses, retries, timeouts, cancellation
- Conversation search, rename, export and deletion
- Prompt profiles and configurable personality
- Usage and latency telemetry

## Phase 2 — Neural Memory
- User-approved memory capture
- Memory review, correction, export and deletion
- Semantic retrieval and source attribution
- Project/document knowledge spaces
- Retention controls and privacy boundaries

## Phase 3 — Autonomous Agent Engine
- Task decomposition and planning
- Agent/tool registry and capability permissions
- Durable task queue and execution state
- Human approval gates for consequential actions
- Cancellation, audit trail, retries and recovery

## Phase 4 — Voice Intelligence
- Speech input and output
- Bilingual Bangla/English handling
- Interruptions, push-to-talk and accessibility controls

## Phase 5 — Coding and GitHub Intelligence
- Repository context and code navigation
- Branch, commit, issue and pull-request workflows
- Diff review and test feedback
- Explicit approval before repository writes

## Phase 6 — Browser Automation
- Browser task planning and visible execution log
- Site-specific permissions and safe session handling
- Approval before form submission, purchases, publishing, or destructive changes

## Phase 7 — Security and reliability
- Authentication and per-user data isolation
- Encryption and secret management
- Threat modeling, dependency scanning and audit logs
- Backups, restore tests, rate limits and abuse protection

## Phase 8 — Android and Web releases
- Responsive web deployment
- Android packaging and signed release pipeline
- Device compatibility, accessibility and performance testing
- Release notes and rollback plan

## Definition of done
A milestone needs working implementation, automated tests, a successful build, updated documentation, and known limitations. Never mark a feature complete based on UI appearance alone.
